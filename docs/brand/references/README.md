# 레퍼런스 저장소

이나래를 이루는 것들을 쌓아두는 곳. 대화는 컴퓨터를 바꾸면 사라지고 다른 사람은 볼 수 없다. **여기 넣은 것만 남는다.**

## 왜 이미지인가

[foundation.md](../foundation.md) 4절 표현 원칙 — 감각은 글이 아니라 **색상·구성·디자인**에 있다. 말로 옮기면 손실이 크다. 그래서 원본을 그대로 둔다.

## 넣는 법

1. 이미지를 이 폴더에 넣는다. 파일명은 `무엇-무엇.jpg` 형태로 알아볼 수 있게.
2. 아래 목록에 한 줄 추가한다. **좋음인지 아님인지 반드시 표시한다.**
3. 캡션은 **"왜 좋은지" 설명하지 않는다.** 어디가 그렇게 만드는지, 또는 언제·어디서 온 것인지만 적는다.

## 무엇을 넣으면 좋은가

정보량이 큰 순서다.

1. **경계** — 비슷해 보이는데 "이건 아니다"인 것. 좋아하는 것만으로는 축이 안 잡힌다. 경계가 축이다. → [foundation.md 5-4절](../foundation.md)
2. **고르는 순간** — 완성품보다 재료를 고르고 배열을 정하는 단계. 같은 꽃을 검정+민트로 한 것과 빨강+민트로 한 것이 갈린 지점.
3. **산 것** — 말보다 강한 증거. 끌렸는데 안 산 것도 좋다. 멈춘 지점이 경계다.
4. **만든 것** — 시기와 맥락을 같이 적는다.

**같은 대상의 시기별 변화**도 크다. 유오가 그 예다 — 브랜드 전체가 아니라 특정 시기가 레퍼런스다.

## 파일 규칙

- **JPEG로 넣는다.** 폰 캡처는 PNG로 나오고 7MB를 넘기도 한다. 저장소가 무거워지면 클론과 PR 리뷰가 느려진다.
- 가로 1200px, 품질 88 정도면 충분하다. 변환은 이미 설치된 `sharp`로 한다.
- `.gitattributes`가 이미지 확장자를 binary로 잡아두어 줄바꿈 변환은 일어나지 않는다.
