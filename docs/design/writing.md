# 문구 — 손님에게 하는 말

> [tokens.md](tokens.md) 가 색과 크기의 규약이라면, 이 문서는 **말의 규약**이다.
> 브랜드의 목소리를 정하는 것은 이나래이고, 여기는 **매번 묻지 않아도 되도록 경계를 적어두는 곳**이다.

## 0. 왜 — 먼저 재봤다

지금 손님이 보는 말은 **293줄 · 26개 파일**에 흩어져 있다. 대부분 개발하면서 적은 것이다.

| 무엇        | 지금                                                                  |
| ----------- | --------------------------------------------------------------------- |
| 영문 라벨   | 서로 다른 것 16종 (`Total` `SHOP` `Sold Out` `Our Story` …)           |
| 실패 문구   | **스무 군데쯤이 「…하지 못했습니다」로 끝난다** — 뭘 해야 하는지 없다 |
| 말투        | 「담긴 것이 없습니다」와 「최근에 주문하신 상품이…」가 한 화면에 있다 |
| 버튼과 안내 | 같은 말을 두 번 한다 (2026-09-30에 세 군데 걷어냈다)                  |

## 1. 경계 — **조형 라벨**과 **말** ★

말이 둘로 나뉜다. **이 선이 이 문서에서 제일 중요하다** — 언어가 둘이 되면 여기서 갈린다.

### 조형 라벨 — 영문으로 고정한다. 번역하지 않는다

작고 회색이고 대문자인 것들. `text-label`·`text-caption` 에 `uppercase tracking-widest` 가 붙은 자리다.

```
SHOP   ORDER   BRAND   TOTAL   CART   SIGN IN   LANGUAGE
```

**근거는 취향이 아니라 조형이다.** `uppercase` 는 **라틴 문자에만 걸린다.** 한국어를 그 자리에 넣으면 대문자화가 일어나지 않아 **같은 클래스인데 다른 것이 된다.** `tracking-widest` 도 한글 자간에서는 다르게 읽힌다.

즉 **그 자리는 처음부터 영문 자리다.** 계승한 디자인의 「10~11px 대문자 라벨」(CLAUDE.md 1절)이 그것이다.

> ⚠️ **이건 글이 아니라 선이다.** 구획을 나누는 조형이고, 뜻을 전하는 일은 그 아래 내용이 한다. 그래서 **EN 버전에서도 그대로 둔다** — 바뀔 것이 없다.

### 말 — 언어를 따라간다

버튼 · 안내 · 오류 · 상품 정보 · 빈 화면. **KR 이면 한국어, EN 이면 영어.**

### 가르는 기준 한 줄

> **누르면 무슨 일이 일어나는지를 말하면 「말」이다. 구획의 이름이면 「조형」이다.**

「수량」은 구획 이름이므로 조형이다 — 그런데 지금 한국어다. 옛 사이트에서도 **같은 자리에 「수량」과 `Total` 이 섞여 있었다.** 그건 계승할 규칙이 아니라 흘러온 상태다.

## 2. 지금 어긋나 있는 것

| 지금                   | 어디             | 어느 쪽인가                      |
| ---------------------- | ---------------- | -------------------------------- |
| `Total`                | 장바구니 · 상세  | 조형 ✅ 그대로                   |
| `SHOP` `ORDER`         | Footer · Sidebar | 조형 ✅ 그대로                   |
| `Option`               | VariantPicker    | 조형 ✅ 그대로                   |
| **「수량」**           | VariantPicker    | 조형인데 **한국어** → `QUANTITY` |
| **`Add to Cart`**      | 상세             | **말인데 영문** → 아래 3번       |
| **`Buy It Now`**       | 상세             | **말인데 영문** → 아래 3번       |
| **`Sold Out`**         | 상세             | **말인데 영문** → 아래 3번       |
| `Detail`               | ProductTabs      | 경계 — 탭 이름이라 조형에 가깝다 |
| `Our Story` `Lookbook` | 첫 화면          | 구획 이름 → 조형 ✅              |
| `Not Found`            | 404              | **말** → 「찾을 수 없습니다」    |

## 3. ⚠️ 이나래가 정할 것 — 버튼을 영문으로 둘까

위 표의 셋(`Add to Cart` · `Buy It Now` · `Sold Out`)이 **이 문서가 혼자 정할 수 없는 자리**다.

기준대로면 **말**이므로 한국어여야 한다. 그런데 그 버튼은 `tracking-widest uppercase` 검은 면이라 **한국어를 넣으면 조형이 달라진다.** 「장바구니에 담기」는 `ADD TO CART` 와 다른 물건이다.

| 어떻게                 | 얻는 것                           | 잃는 것                                                       |
| ---------------------- | --------------------------------- | ------------------------------------------------------------- |
| 영문 그대로            | 계승한 조형 유지                  | **KR·EN 버전이 같아진다.** 처음 오는 손님이 읽지 못할 수 있다 |
| 한국어로               | 기준이 하나가 된다 · EN 과 갈린다 | 대문자 조형을 버린다                                          |
| **버튼만 예외로 둔다** | 조형 유지 + 기준에 구멍 하나      | 예외가 하나 생기면 다음 예외가 쉬워진다                       |

**정해지기 전까지 손대지 않는다.**

## 4. 실패했을 때 — 무엇을 해야 하는지 말한다 ★

지금 실패 문구는 대부분 **일어난 일만** 말한다.

```
❌  주문을 완료하지 못했습니다.
❌  결제를 준비하지 못했습니다.
❌  주문하지 못했습니다. 잠시 뒤 다시 시도해 주세요.
```

**손님이 다음에 무엇을 해야 하는지가 없다.** 「잠시 뒤 다시」는 그것을 말한 척하는 문장이다 — 정말로 기다리면 되는 경우에만 쓴다.

### 담을 것 둘

1. **무엇이 막혔나** — 한 문장
2. **이제 무엇을 하면 되나** — 할 수 있는 일이 있을 때만

```
✅  브릭가든 이(가) 방금 품절됐습니다. 결제를 취소했습니다.
✅  주문을 완료하지 못했습니다. 결제는 그대로 있습니다 — 주문 내역에서 다시 확인해 주세요.
```

**설명을 늘려 풀지 않는다** (CLAUDE.md 표현 원칙). 두 문장을 넘기면 대개 화면이 잘못된 것이다.

### 손님 탓으로 들리게 쓰지 않는다

```
❌  잘못 입력하셨습니다
✅  받는 분·연락처·주소를 채워 주세요
```

## 5. 말투 — 하나로

- **「…습니다」로 끝낸다.** 「…해요」를 섞지 않는다
- **높임은 손님의 행동에만.** 「주문하신 상품」은 맞고, 「담긴 것이 없습니다」도 맞다 — 물건은 높이지 않는다
- **「고객님」을 쓰지 않는다.** 부르지 않아도 문장이 성립한다

## 6. 버튼

- **동사로 끝낸다** — 「주문하기」 「결제하기」 「빼기」
- **버튼이 한 말을 아래에서 또 하지 않는다.** 2026-09-30에 「결제는 아직 준비 중입니다」류 셋을 걷어낸 것이 그 예다
- **진행 중에도 같은 말을 쓴다** — 「결제하기」 → 「결제를 여는 중…」. 다른 단어로 바꾸면 다른 버튼처럼 보인다

## 7. 언어가 둘이 될 것을 염두에 둔 제약 ★

지금은 KR 하나지만 Sidebar 에 `KR · EN` 자리가 이미 있다. **나중에 고생하지 않으려면 지금 지킬 것이 셋이다.**

**① 문장을 조각내 이어붙이지 않는다.**

```
❌  {name} + ' 은(는) 품절됐습니다'      ← 영어는 어순이 다르다
✅  `${name} 이(가) 품절됐습니다`        ← 문장 하나가 통째로 번역 단위
```

**② 숫자·이름은 자리표시자로 끼운다.** 문장을 잘라 앞뒤로 붙이지 않는다.

**③ 조형 라벨은 번역 대상이 아니다.** 1절의 그 목록은 언어가 바뀌어도 그대로다. **번역 파일에 넣지 않는다** — 넣는 순간 누군가 번역한다.

> 번역을 **지금 넣지는 않는다.** 문자열을 한 군데로 모으는 일은 EN 을 실제로 열기로 할 때 한다. 지금은 **위 셋만 지켜두면** 그때 옮기는 것이 기계적인 일이 된다.
