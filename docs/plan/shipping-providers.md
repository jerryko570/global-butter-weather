# 택배사 — 무엇을 고를 것인가 (2026-09-27 조사)

> 결제사 조사([payment-providers.md](payment-providers.md))와 같은 성격의 문서다. **정하는 것은 이나래이고, 여기는 판단에 필요한 것만 모은다.**

## 0. 먼저 — 배송비 3,000원이 원가보다 낮을 수 있다 ★

지금 우리 규칙은 **3,000원 / 상품 5만원 이상 무료**다 (`lib/shipping.ts`).

조사한 요금과 나란히 놓으면 이렇다.

| 보내는 법                | 500g 기준     | 우리가 받는 3,000원과 |
| ------------------------ | ------------- | --------------------- |
| GS25 반값택배            | 1,900원       | 남는다                |
| CU 알뜰택배              | 1,800원       | 남는다                |
| **편의점에서 일반택배**  | 3,400원~      | **모자란다**          |
| **우체국 창구접수**      | 4,000원       | **모자란다**          |
| **우체국 방문접수**      | 5,000원       | **모자란다**          |
| **GS 포스트너 (사업자)** | 3,200~3,400원 | **모자란다**          |
| 계약 택배 (물량 있을 때) | 견적          | 대개 남는다           |

**문앞까지 보내면서 계약이 없으면 한 건마다 손해가 난다.** 무료 배송 구간(5만원 이상)에서는 그 손해가 그대로 마진에서 빠진다.

셋 중 하나를 골라야 한다 — ⑴ 배송비를 올린다 ⑵ 반값택배로 간다 ⑶ 계약 단가를 받아온다. **이건 가격 정책이라 이나래 판단이다.**

## 1. 우리 물건은 작고 가볍다

키링·팔찌·목걸이다. **거의 전부 500g 이하**로 들어간다. 그래서 무게 구간이 올라가며 벌어지는 차이는 우리와 상관이 없고, **가장 가벼운 구간의 단가와 「어디서 받는가」만 남는다.**

### 반값택배 — 제일 싸지만 손님이 편의점에 간다

GS25 반값택배 1,900원, CU 알뜰택배 1,800원. **점포에서 점포로 보내고 손님이 편의점에서 찾는다.** 2026년 1월부터 롯데택배가 맡아 하루 만에 간다.

싼 이유가 곧 제약이다. **문 앞에 두고 가지 않는다.**

> ⚠️ **이건 가격 문제가 아니라 브랜드 문제다.** 「나의 하루에 부드럽게 스며드는 작은 온기」를 편의점에서 찾아가게 할 것인지 — 포장을 열기까지의 경험이 브랜드의 일부라면 여기서 갈린다. **이나래가 정할 일이다.**

### 문앞 배송 — 계약이 없으면 비싸다

| 방법                 | 요금                          | 비고                        |
| -------------------- | ----------------------------- | --------------------------- |
| 편의점 접수 일반택배 | 3,400원(동일권)~3,900원(타권) | 접수하러 편의점에 가야 한다 |
| 우체국 창구접수      | 4,000원 (3kg 이하)            | 우체국까지 들고 간다        |
| 우체국 방문접수      | 5,000원 (5kg 이하)            | 가지러 온다                 |

우체국은 **월 1~500건까지 단가가 같다.** 최소 물량이 없어 초반에 계약 부담이 없다는 뜻이다. 대신 소량 방문접수는 비싸다.

계약 택배(CJ·로젠·한진 등)는 **월 물량이 있어야 단가가 나온다.** 지금 물량으로는 협상이 안 된다 — 나중 일이다.

## 2. API 는 택배사가 아니라 「중개」를 통한다 ★

여기서 기대가 한 번 꺾인다.

**송장을 코드로 발행하는 API 는 계약 고객에게만 열린다.** 택배사에 직접 붙는 길은 물량이 먼저다. 소량 판매자는 **굿스플로(goodsFLOW)** 같은 중개 서비스를 통해 여러 택배사를 한 규격으로 쓴다 — 포트원이 PG 를 묶어주는 것과 같은 구조다.

**그리고 반값택배·알뜰택배에는 발행 API 가 없다.** 앱이나 점포 키오스크에서 한 건씩 접수한다. **제일 싼 선택지가 제일 자동화가 안 되는 선택지다.**

### 조회는 지금도 붙일 수 있다

발행과 조회는 다른 일이다. **배송 조회 API 는 계약 없이 쓸 수 있는 것이 있다** — 스윗트래커의 스마트택배 API 가 대표적이고, 택배사 코드와 송장번호를 주면 현재 위치를 돌려준다.

즉 지금 할 수 있는 것은 이 모양이다.

```
송장 발행   사람이 한다 (편의점 앱 · 우체국 창구)
송장 번호   어드민에 손으로 넣는다
배송 조회   API 로 붙인다 — 손님이 주문 내역에서 본다
```

**물량이 붙으면 발행만 자동으로 바꾼다.** 송장번호를 담는 자리와 조회는 그대로 쓴다.

## 2-5. 정해졌다 — **GS 포스트너** (2026-09-27) ★

이나래가 **문앞 배송으로 간다**고 정했다. 반값택배(편의점 수령)는 쓰지 않는다. 「배송비가 들더라도 고객의 집앞으로」.

그 조건 — **비정기 · 소량 · 문앞** — 에서 가장 싼 것은 **GS25 편의점택배의 사업자 제도(GS 포스트너)** 다.

| 보내는 법                | 2kg 이하          | 타권 할증 | 최소 물량 |
| ------------------------ | ----------------- | --------- | --------- |
| **GS 포스트너 (사업자)** | **3,200~3,400원** | **없음**  | **없음**  |
| 편의점 일반 접수 (개인)  | 3,400 / 3,900원   | 있음      | 없음      |
| 우체국 창구접수          | 4,000원           | 없음      | 없음      |
| 우체국 방문접수          | 5,000원           | 없음      | 없음      |
| 계약 택배 (CJ·로젠 등)   | 견적              | —         | **있다**  |

### 왜 이것인가

- **최소 물량 요건이 없다.** 사업자등록증상의 대표자면 가입된다. 비정기 소량이라는 우리 조건에 정확히 맞는다
- **타권 할증이 없다.** 동일권·타권이 같은 값이라 제주·도서를 빼면 전국이 한 가격이다. **배송비를 하나로 정할 수 있다**
- **24시간 접수.** 우체국은 창구 시간에 매여 있고, 방문접수는 소량이면 비싸다
- 등급이 올라가면 더 싸진다 (에이스 200건/3개월, 프리미어 300건/3개월). 지금은 기본 등급이다

### 먼저 필요한 것 — 사업자등록 ★

**GS 포스트너는 사업자등록증이 있어야 가입된다.** 그런데 이건 결제 실연동(토스페이먼츠 계약)에도 필요하다 — **같은 문이다.** 사업자등록 · 통신판매업 신고를 하면 둘이 같이 열린다.

그 전까지는 **개인 자격으로 편의점 일반택배**(3,400/3,900원)를 쓴다. 같은 창구라 나중에 옮길 때 방식이 바뀌지 않는다.

### 아직 확인 못 한 것

- **송장 발행 API 는 포스트너에도 없다고 본다.** 예약 앱으로 접수하고 송장번호를 받는 구조다. 확인이 필요하다
- 제주·도서 추가 요금
- 반품 서비스의 조건 (포스트너에 포함돼 있다고 한다)

> **우체국 계약소포도 후보로 남겨둔다.** [간편견적](https://biz.epost.go.kr/ui/index.jsp)에 물량을 넣으면 실시간으로 단가가 나온다. 포스트너보다 싸게 나오면 그때 바꾼다 — **어느 택배사든 담을 수 있는 자리**를 만들어 둘 이유가 이것이다.

## 3. 그래서 지금 정할 것

| 무엇                     | 상태                                                  |
| ------------------------ | ----------------------------------------------------- |
| 반값택배를 쓸까          | ✅ **안 쓴다.** 문앞 배송으로 간다 (2026-09-27)       |
| 택배사                   | ✅ **GS 포스트너** (사업자등록 뒤)                    |
| **배송비**               | ✅ **3,500원** (2026-09-27). 무료 기준 5만원은 그대로 |
| 송장번호 자리 + 조회 API | ⬜ 지금 만들 수 있다                                  |

**배송비만 남았다.** 원가가 **3,200~3,400원**이므로 3,000원은 그대로 둘 수 없다. 세 갈래다.

| 어떻게             | 손님이 보는 것    | 우리가 지는 것               |
| ------------------ | ----------------- | ---------------------------- |
| 3,500원으로 올린다 | 500원 오른다      | 포장재만 우리 몫             |
| 3,000원을 유지한다 | 그대로            | 한 건마다 200~400원 + 포장재 |
| 무료로 돌린다      | 배송비가 사라진다 | 전부. 대신 상품가에 들어간다 |

**무료 기준(지금 5만원)도 같이 봐야 한다.** 11,900원짜리 키링이라 대부분의 주문이 무료 구간에 닿지 않는다 — 즉 **거의 모든 주문에서 배송비를 받는다.**

## 4. 확인해야 하는 것

조사는 공개된 요금표 기준이다. **실제로 쓸 때는 달라질 수 있다.**

- 편의점택배의 **사업자 회원 할인** — 있다고 하는데 조건과 폭을 확인하지 못했다
- 반값택배의 **셀러용 대량 접수** 창구가 있는지
- 굿스플로의 **최소 물량·수수료** — 공개돼 있지 않아 문의가 필요하다
- 제주·도서 지역 추가 요금 (우리 규칙에 그 구분이 아직 없다)
