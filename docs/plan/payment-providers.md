# 결제사 조사 — 무엇을 고를 것인가

> 2026-09-21 조사. **이나래가 결정한다.** 이 문서는 고르기 위한 재료다.
>
> 숫자는 공개된 자료에서 옮긴 것이고 **계약 조건은 협의로 달라진다.** 여기 적힌 값으로 계약을 판단하지 말 것 — 실제 요율은 신청해 봐야 안다.

## 정해진 것

- **회원만 산다** (구글·카카오 OAuth). `orders.user_id` 가 `not null`
- **재고는 결제 완료 때 깎는다.** `mark_order_paid()` 가 조건부로 빼고, 모자라면 전체가 되돌아간다
- **스키마는 결제사를 모른다.** `payment_provider` · `payment_id` 두 칸뿐이라 **무엇을 고르든 스키마를 안 고친다**

## 이나래가 말한 조건

1. **토스가 좋겠지만 다른 것도 괜찮다**
2. **위챗페이를 쓸 수 있으면 좋겠다**
3. **포트원은 재고한다** — 「너무 느려서 좋은 경험이 없었다」

---

## ⚠️ 먼저 — 결제사보다 앞선 관문이 있다

**어느 곳을 고르든 사업자등록증과 통신판매업 신고가 필요하다.** 개인 명의로는 PG 계약이 안 된다.

토스페이먼츠 기준으로 **사업자등록증 · 통장사본 · 대표자 신분증**이 필요하고, 상품이 전자상거래법에 맞는지와 통신판매업 신고 여부를 본다.

**스마트스토어를 운영했다면 이미 있을 가능성이 높다.** 없다면 그것이 결제보다 먼저다.

---

## 1. 토스페이먼츠 — 국내는 여기가 무난하다

|          |                                                                                       |
| -------- | ------------------------------------------------------------------------------------- |
| 결제수단 | 카드 · 간편결제(토스페이·네이버페이·카카오페이·페이코) · 계좌이체 · 가상계좌 · 휴대폰 |
| 해외     | **해외카드(VISA·MASTER·JCB·유니온페이) · PayPal**                                     |
| 수수료   | 카드 일반 3.4%. **영세 0.63% / 중소1 1.15% / 중소2 1.40% / 중소3 1.74%**              |
| 정산     | 카드 T+3, 간편결제·계좌이체 T+1                                                       |

**영세·중소 구간이 크다.** 시작하는 가게는 3.4%가 아니라 0.63~1.74%일 가능성이 높다. 이것이 토스의 실제 매력이다.

### ❌ 위챗페이·알리페이가 안 된다

[공식 문서](https://docs.tosspayments.com/guides/v2/learn/foreign-payment)에 해외 결제는 **해외카드와 PayPal 뿐**이라고 되어 있다. 위챗페이·알리페이는 명시적으로 없다.

---

## 2. 위챗페이를 하려면 — KICC · 페이레터 · 엑심베이

|               | KICC        | 페이레터       | 엑심베이 |
| ------------- | ----------- | -------------- | -------- |
| 알리페이      | 2.60~2.70%  | 3.60%          | 2.90%    |
| **위챗페이**  | **2.30%**   | 3.60%          | 2.80%    |
| 가입비·연회비 | **없음**    | 있음           | 있음     |
| 정산          | D+4 영업일  | 매주 목요일    | —        |
| 롤링 리저브   | 없음        | **10%, 180일** | 없음     |
| 카드 결제     | **안 된다** | 된다           | 된다     |

**KICC 가 가장 싸고 가입 부담이 없다.** 다만 **카드가 안 된다** — 국내 손님을 받으려면 다른 곳이 하나 더 있어야 한다.

> **롤링 리저브**는 매출의 일부를 일정 기간 묶어두는 것이다. 페이레터의 10%·180일은 **팔린 돈의 10%가 반년 동안 안 들어온다**는 뜻이다. 작은 가게에 그 부담은 작지 않다.

> 엑심베이는 초기 한도가 **월 USD 1,000** 으로 낮다.

---

## 3. 「토스 + 위챗페이」는 한 곳으로 안 된다

둘 중 하나를 골라야 한다.

### ① 두 곳을 각각 붙인다

토스(국내) + KICC(위챗페이). **각각 계약·심사·정산·연동이 따로**다. 관리할 것이 두 배가 되지만 중간 층이 없다.

### ② 통합 레이어를 쓴다 — 그게 포트원이다

**포트원은 PG 가 아니다.** 여러 PG 를 하나의 규격으로 묶는 층이다. 그래서 **포트원을 써도 PG 계약은 따로** 해야 하고, 수수료도 PG 것이 중심이다.

|               |                                     |
| ------------- | ----------------------------------- |
| 포트원 이용료 | **월 순거래액 5,000만원 미만 무료** |
| PG 수수료     | 별도. 계약한 PG 의 요율             |

### 「포트원이 느렸다」를 어떻게 볼 것인가

**포트원은 PG 가 아니라 층이다.** 결제창을 띄우고 승인하는 것은 그 아래 PG 다. 그래서 느렸던 것이 **포트원인지, 그 아래 PG 인지, 옛 SDK(V1)인지** 갈린다.

지금은 **V2 SDK** 가 현행이다. 옛 경험이 V1 이었다면 같은 느낌이 아닐 수 있다.

**확인할 방법** — 그때 어느 PG 를 통해 결제했는지 기억나면 그것이 답에 가깝다. 기억나지 않으면, 결정 전에 **토스 단독으로 한 번 붙여보고 체감을 비교**하는 것이 가장 확실하다. 스키마가 결제사를 모르므로 바꿔 끼우는 비용이 크지 않다.

---

## 고를 때 물어야 할 것

1. **중국 손님이 지금 있는가, 앞으로 생길 것인가.** 위챗페이는 **없으면 0원, 있으면 결제 자체가 불가능**한 종류의 수단이다. 「있으면 좋다」로는 두 곳을 붙일 이유가 안 된다
2. **사업자등록·통신판매업 신고가 되어 있는가.** 안 되어 있으면 그것이 먼저다
3. **처음부터 둘 다인가, 국내 먼저인가.** 스키마가 결제사를 모르므로 **나중에 더하는 비용이 크지 않다**

## 이 문서가 결정하지 않는 것

**어느 곳을 고를지 정하지 않는다.** 수수료·정산·심사는 돈과 계약의 문제이고 브랜드 밖의 판단이다 (CLAUDE.md 8절).

다만 **하나만 고르라면 토스로 시작하는 쪽**이 근거가 있다 — 영세·중소 구간이 크고, 국내 손님이 지금의 전부이며, 위챗페이는 나중에 KICC 를 하나 더 붙이면 된다. **결정은 이나래가 한다.**
